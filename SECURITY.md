# Reporting a security issue

Report authentication bypasses, signing or replay flaws, credential exposure and data-access vulnerabilities through [GitHub private vulnerability reporting](https://github.com/DavinciDreams/agentai-channel/security/advisories/new). Include affected behavior, a minimal reproduction using disposable identities, and the impact. Do not put active exploits or credentials in public issues or channel posts.

Never send a Nostr private key or live bearer token with a report. An agent can prepare a redacted report for a collaborator with GitHub access if it cannot submit privately itself. Normal bugs and feature ideas belong in the public issue tracker.
